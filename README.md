## 🐍 Python Programs

1. [Hello World](Python/hello_world.py) — Prints a welcome message.
2. [Factorial](Python/factorial.py) — Calculates the factorial of a non-negative integer.
3. [Palindrome](Python/palindrome.py) — Checks whether a word reads the same forward and backward.

Example:

```python
print("Hello, World!")
```

## ☕ Java Programs

1. [Hello World](Java/HelloWorld.java) — Prints a welcome message.
2. [Factorial](Java/Factorial.java) — Calculates the factorial using a loop.
3. [Palindrome](Java/Palindrome.java) — Checks a word using `StringBuilder`.

Example:

```java
System.out.println("Hello, World!");
```

## 🟨 JavaScript Programs

1. [Hello World](JavaScript/hello-world.js) — Prints a message to the console.
2. [Factorial](JavaScript/factorial.js) — Calculates the factorial using a loop.
3. [Palindrome](JavaScript/palindrome.js) — Checks whether a string is a palindrome.

Example:

```javascript
console.log("Hello, World!");
```

## ▶️ How to Run

### Python

```bash
python Python/hello_world.py
python Python/factorial.py
python Python/palindrome.py
```

### Java

Compile and run each program from the repository root:

```bash
javac Java/HelloWorld.java
java -cp Java HelloWorld
```

For the other Java programs, replace `HelloWorld` with `Factorial` or `Palindrome`.

### JavaScript

```bash
node JavaScript/hello-world.js
node JavaScript/factorial.js
node JavaScript/palindrome.js
```

**Requirements:** Python 3, JDK, and Node.js for the respective languages.
